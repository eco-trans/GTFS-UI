# GTFS-UI
Analysis of GTFS data in USA

APP: https://eco-trans.github.io/GTFS-UI/


Disclaimer: All data presented in this dashboard, including delay and On-Time Performance (OTP) metrics, are derived from GTFS-Realtime (GTFS-rt) Trip Updates. GTFS-rt is primarily intended to provide real-time passenger information and enhance the traveler experience; it is not designed or validated for post-operation performance evaluation or official reporting. Consequently, the analyses and results presented in this dashboard are subject to the limitations and potential inaccuracies inherent in GTFS-rt data. These results should not be used as the sole basis for operational assessment, regulatory reporting, contractual performance evaluation, or other official decision-making purposes. Any conclusions drawn from this dashboard should be interpreted with appropriate caution and, where possible, validated using authoritative operational data sources.
